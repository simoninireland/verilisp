Using Verilisp
==============

Verilisp can be used in two different ways:

- From :ref:`within Common Lisp <verilisp-from-lisp>`, either
  interactively or in compiled code, exactly like any other Common
  Lisp system; or
- As a traditional :ref:`stand-alone compiler <verilispc>` that reads
  Common Lisp files and produces Verilog for any Verilisp structures
  defined by that code.
